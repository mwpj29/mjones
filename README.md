# MJ Engineering website

A lightweight, responsive static website designed for GitHub Pages.

## Update before publishing

Replace the placeholder email address in `index.html`:

```html
mailto:your-email@example.com
```

Review the company name, service descriptions and location, then adjust them to match the business.

## Preview locally

Open `index.html` in a browser. No installation or build command is required.

## GitHub Pages

In the GitHub repository, open **Settings > Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.
